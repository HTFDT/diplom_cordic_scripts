# ref_comparer.exe — верификация результатов макроса MiniTera (CORDIC sin) по формальной модели (cordic_sin.exe)

## Назначение

`ref_comparer.exe` сравнивает значения, полученные на выходах ПЭ в IDE MinTera (снятые через breakpoints и сохранённые в бинарные файлы), с эталонными значениями, рассчитанными формальной моделью `compute_sin.exe`.

Утилита позволяет:
- проверить совпадение `cos(x)`, `sin(y)` и `z` на выбранных итерациях CORDIC;
- проверить финальный результат макроса;
- получить отчёт в формате JSON с отметкой `OK/ERR` и двоичными словами эталона/факта.

## Входные данные

Утилита принимает **конфигурационный файл JSON**, который описывает:
- разрядность слова (без старт-бита);
- используется ли старт-бит;
- входной аргумент (BAM-угол, 32 бита: 2 бита квадранта + 30 бит угла);
- для каждой итерации: файл(ы) с потоками `cos/sin/z` и битовое смещение, откуда начинать извлечение слова;
- файл с финальным результатом.

### Пример структуры конфига

```json
{
  "bits": 32,
  "start-bit": true,
  "arg": "01000000000000000000000000000000",
  "iterations": {
    "4": {
      "offset": 135,
      "cos": { "file": "iter4_x.bin" },
      "sin": { "file": "iter4_y.bin" },
      "z":   { "file": "iter4_z.bin" }
    }
  },
  "result": { "offset": 0, "file": "out.bin" }
}
```

**offset** задаётся в битах от начала файла (0-based).  
Если `iterations[k].offset` указан, он считается значением по умолчанию для `cos/sin/z`.  
При необходимости его можно переопределить на уровне компоненты: `iterations[k].cos.offset`.

## Выходной формат

По каждой итерации и по финальному результату формируется отчёт:

- `status`: `"OK"` если слова совпадают, иначе `"ERR"`;
- `reference`: двоичная строка эталонного слова;
- `value`: двоичная строка слова, извлечённого из файла.

Пример:

```json
{
  "iterations": {
    "4": {
      "cos": { "status": "OK", "reference": "....", "value": "...." },
      "sin": { "status": "ERR", "reference": "....", "value": "...." },
      "z":   { "status": "OK", "reference": "....", "value": "...." },
      "status": "ERR"
    }
  },
  "result": {
    "status": "OK",
    "reference": "....",
    "value": "...."
  }
}
```

## Запуск

### CLI
```bash
./ref_comparer.exe config.json
```

Опционально:
- `--bits N` — разрядность по умолчанию (может быть переопределена `cfg.bits`);
- `--iterations N` — разрядность по умолчанию (может быть переопределена `cfg.iterations-count`);
- `-o out.json` — записать отчёт в файл.

Пример:
```bash
./ref_comparer.exe --bits 32 -o report.json config_90.json
```

### REPL (интерактивно)

Запуск без аргументов
```bash
ref_comparer.exe
```

Ввод пути к конфигу
```
> config_90.json
```

Команды REPL:
- `:bits N`
- `:out FILE` / `:out -`
- `:status`
- `:help`
- `quit`

## Замечания

- Проверка корректна только при правильном указании `offset` для соответствующего файла/итерации.
